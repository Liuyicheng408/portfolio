# 个人展示网站 · 产品需求文档（PRD）

| 项 | 内容 |
|---|---|
| 项目名称 | 个人主页 Portfolio |
| 版本 | v1.0 |
| 形态 | 单页滚动站点（SPA） |
| 部署 | Cloudflare Pages / Vercel（静态托管） |

---

## 一、项目目标

在求职与课程展示场景下，用**一页网站**完整呈现「我是谁、我会什么、我做过什么、怎么联系我」。
访客 30 秒内能建立基本印象，并能快速跳到项目细节与联系方式。

### 目标用户
| 用户 | 诉求 |
|---|---|
| 招聘方 / 面试官 | 快速判断技术方向与项目质量 |
| 同学 / 同行 | 看项目、读文章、交流 |
| 课程评审 | 检查设计完成度与个性化程度 |

---

## 二、功能需求

| 编号 | 模块 | 需求 | 优先级 |
|---|---|---|---|
| FR-01 | 导航 | 固定顶栏，滚动时添加毛玻璃背景，高亮当前区块 | Must |
| FR-02 | 导航 | 移动端折叠为汉堡菜单 | Must |
| FR-03 | 首屏 | 姓名、身份、一句话介绍、CTA 按钮、数据统计 | Must |
| FR-04 | 首屏 | 右侧头像轨道动画 + 漂浮技术标签 | Should |
| FR-05 | 关于 | 个人简介卡 + 成长时间线 | Must |
| FR-06 | 技能 | 按前端 / 后端 / AI 分组，带熟练度进度条 | Must |
| FR-07 | 项目 | 卡片网格：渐变封面、描述、技术标签、详情入口 | Must |
| FR-08 | 博客 | 文章列表（日期 / 标题 / 摘要），点击弹窗阅读全文 | Must |
| FR-09 | 联系 | 邮箱一键复制、社交链接、留言表单 | Must |
| FR-10 | 视觉 | 深色星空背景（Canvas 粒子 + 流星） | Must |
| FR-11 | 视觉 | 滚动进入动画（IntersectionObserver 渐显） | Should |
| FR-12 | 适配 | 1440 / 1024 / 768 / 375 四档不破版 | Must |

### 非目标
- 后台管理系统、文章在线编辑
- 多语言切换
- 访问统计与埋点

## 三、设计规范

### 3.1 视觉方向
深空科技感：近黑背景 + 星点 + 星云辉光，内容用半透明玻璃卡片浮在其上，强调色为青→紫→粉的渐变。

### 3.2 色彩
| 用途 | 色值 |
|---|---|
| 背景 | #05060B |
| 面板 | rgba(255,255,255,0.04) |
| 描边 | rgba(255,255,255,0.09) |
| 主文字 | #E8ECF6 |
| 次文字 | #9AA4BD |
| 强调渐变 | #22D3EE → #8B5CF6 → #EC4899 |

### 3.3 字体与间距
- 系统字体栈（无外链字体，保证离线可打开）
- 标题 clamp(28px, 3.4vw, 42px)，正文 14–15px，行高 1.8
- 区块纵向留白 110px，内容最大宽度 1120px

### 3.4 动效
- 星点缓慢漂移与呼吸闪烁，流星每 3.5–8 秒随机出现
- 卡片 hover 上浮 4–6px
- 元素进入视口时上移淡入，时长 0.7s

---

## 四、验收标准

1. 桌面与手机端均无横向滚动、无文字截断
2. 导航点击可平滑跳转，当前区块高亮正确
3. Canvas 星空流畅（≥50fps），切到后台自动暂停
4. 博客弹窗可打开、关闭，内容正常
5. 邮箱复制有反馈
6. 内容全部集中在 `src/data/profile.js`，改一处即可换人
7. 已部署到 Cloudflare Pages / Vercel，公网可访问
